# habit-dots

DotHabit を置き換える自分用の習慣記録アプリ（PWA）。

## 使い方

GitHub Pages で公開された URL を Safari で開き、共有 → 「ホーム画面に追加」。
一度その状態で開けば、以降は圏外でも起動する。

## ファイル

| ファイル | 中身 |
|---|---|
| `SPEC.md` | 仕様書。実装はこれに従う |
| `index.html` | アプリ本体（HTML + CSS + JS すべて） |
| `sw.js` | Service Worker（オフライン用） |
| `manifest.webmanifest` | アプリ名・アイコン・起動設定 |

## 移行データについて

`dothabit-migration.json`（DotHabit から復元した8習慣・2,366日ぶんの記録）は、
個人の記録が入っているため**リポジトリには含めない**（`.gitignore` 済み）。

アプリ完成後、設定の「データのバックアップ」→「読み込み」に貼り付けて取り込む。

## 変更するとき

`index.html` を書き換えたら `sw.js` の `CACHE` 名を必ず上げること。
上げないと、端末に残った古い版が表示され続ける。

## 制約

- フレームワーク・ビルド工程を使わない（素の HTML / CSS / JS のみ）
- 外部 CDN からの読み込みをしない（オフラインで動かなくなるため）
- 詳細は SPEC.md の 1 節を参照
